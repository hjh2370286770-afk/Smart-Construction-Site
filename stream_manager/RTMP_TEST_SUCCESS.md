```bash
cd stream_manager
python test_rtmp_ppe.py
```

### 2. 实时监控（60秒）
```bash
cd stream_manager
python ppe_monitor.py
```

### 3. 集成到主系统

修改 `main_with_ppe.py`:

```python
camera_config = StreamConfig(
    stream_id="cam_001",
    url="rtmp://rtmp05open.ys7.com:1935/v3/openlive/J58749099_1_1?...",
    scene_type="ppe_detection",  # 使用PPE检测
    fps=25,
    buffer_size=5,
    frame_skip=3  # 每3帧检测一次
)
```

## 性能指标

- **检测速度**: ~100-150ms/帧
- **处理能力**: 可以实时处理 25 FPS 视频流
- **建议检测频率**: 每 3-5 帧检测一次（平衡性能和实时性）

## 系统工作流程

```
RTMP 视频流 → FFmpeg 解码 → OpenCV 处理 → PPE 检测 → 结果显示
                ↓
            违规检测 → 截图保存 → 日志记录
```

## 功能特性

✅ **实时检测**: 可以实时处理视频流

✅ **可视化**: 实时显示检测结果和统计信息  
✅ **日志记录**: 自动保存违规截图和日志

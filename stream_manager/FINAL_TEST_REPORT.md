## 🎯 使用方式

### 1. 启动实时监控
```bash
cd stream_manager
python ppe_monitor.py
```

### 2. 按键控制
- `q` - 退出
- `s` - 保存当前帧
- `p` - 暂停/继续

### 3. 修改监控时长
编辑 `ppe_monitor.py`:
```python
monitor.run(duration=300, save_violations=True)  # 监控5分钟
```

## V2版本改进

### 1. 设备状态判断（基于工作模组运动）
**原算法问题**: 使用单帧亮度标准差，导致画面丰富的墙面被误判为移动

**V2改进**: 
- 检测画面上半部分的金属色区域（工作模组）
- 计算模组位置变化（帧间位移）
- 基于模组运动判断设备状态

```python
# 检测金属色区域
metal_mask = cv2.inRange(upper_region, METAL_HSV_RANGE['lower'], METAL_HSV_RANGE['upper'])

# 计算模组位移
if module_detected and prev_module_pos is not None:
    displacement = sqrt((cx - prev_cx)^2 + (cy - prev_cy)^2)
    motion_ratio = displacement / frame_width

# 状态判断
if motion_ratio > 0.05:  # 大幅移动 > 5%画面宽度
    status = "moving"
elif motion_ratio > 0.01:  # 小幅移动
    status = "working"
else:
    status = "idle"
```

### 2. 墙面状态识别（基于颜色）
**判断逻辑**:
- 水泥灰色占比高 (>50%) -> unfinished（未做）
- 白色/浅色占比高 (>60%) -> finished（已做）
- 混合 -> in_progress（施工中）

```python
# 转换到HSV色彩空间
hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)

# 计算水泥色和白色像素比例
cement_mask = cv2.inRange(wall_region, CEMENT_HSV_RANGE['lower'], CEMENT_HSV_RANGE['upper'])
white_mask = cv2.inRange(wall_region, WHITE_HSV_RANGE['lower'], WHITE_HSV_RANGE['upper'])

# 判断墙面状态
if white_ratio > 0.6:
    state = "finished"
elif cement_ratio > 0.5:
    state = "unfinished"
else:
    state = "in_progress"
```

### 3. 帧提取密度增加
**原方案**: 15秒视频提取3帧（5秒间隔）
**V2方案**: 15秒视频提取8帧（2秒间隔）

```python
# 新脚本: extract_frames_dense.py
extract_frames_dense(video_path, output_dir, interval=2.0)
```

### 4. 问题修复
- **API格式问题**：后端返回格式与前端期望不一致
  - 原因：`get_streams()` 直接返回 List，前端期望 `{value: [...], Count: n}`
  - 修复：修改 API 返回格式
  
- **数据持久化问题**：视频流列表没有保存到文件
  - 原因：StreamManager 只在内存中存储，重启后丢失
  - 修复：添加 `_load_streams()` 和 `_save_streams()` 方法

- **前端渲染问题**：检测器数据正常获取但页面显示为空
  - 最终解决：后端持久化问题修复后，前端正常显示

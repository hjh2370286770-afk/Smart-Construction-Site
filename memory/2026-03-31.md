## 关键问题与解决

### 1. 主程序 Web 服务启动失败
**问题**: `main.py --web` 无法启动 Web 服务，但 `test_web.py` 可以
**原因**: 使用 `asyncio.create_task()` 在后台运行 Web 服务器导致事件循环冲突
**解决**: 改为使用单独的线程运行 Web 服务器
```python
import threading
def run_server():
    asyncio.run(self._web_server.serve())
self._web_thread = threading.Thread(target=run_server, daemon=True)
self._web_thread.start()
```

### 2. 前端无法播放视频流
**问题**: 前端提示"视频流加载失败"
**原因**: 浏览器无法直接播放 RTMP 流，需要转换为 MJPEG
**解决**: 
- 后端新增 MJPEG 流端点 `/stream/{camera_id}/mjpeg`
- 前端使用 `<img>` 标签播放 MJPEG 流
- 修复 `CameraDetailView.vue` 传递参数错误（`:stream-url` → `:cameraId`）

### 3. 端口占用问题
**解决**: 停止所有 Python 进程后重新启动

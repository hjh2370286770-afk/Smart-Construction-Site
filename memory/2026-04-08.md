# 对话记忆 - 2026-04-08

## 今日完成的工作

### 1. stream_v3 并发阻塞问题修复

**问题**: 视频流运行时 YOLO 检测阻塞 uvicorn 事件循环，导致所有 API 超时

**修复**:
- `core/stream_processor.py`: 使用 `loop.run_in_executor()` 把 CPU 密集型检测放到线程池
- `core/stream_processor.py`: 添加 `get_latest_frame()` 方法获取缓存帧（带检测框）
- `main.py`: snapshot API 优先使用处理器缓存帧，不再新建 RTMP 连接
- `main.py`: snapshot 端点添加超时保护，失败时返回占位图

### 2. 前端实时刷新

**修改**:
- `web_frontend/index.html`: 添加 `startStreamRefresh()` 函数，每 500ms 刷新一次视频流卡片
- `web_frontend/index.html`: 视频流卡片显示 FPS 信息

### 3. 检测逻辑

**检测器**: `detectors/ppe_detector.py` - 基于 YOLOv8 的 PPE 检测

**检测调用**: `stream_processor.py` 的 `_process_loop()` 中，每隔 `frame_skip` 帧调用一次检测

**违规分析**: `_analyze_detection()` 方法分析检测结果，判断是否违规（no_helmet, no_vest, no_mask）

# 对话记忆 - 2026-04-01

## 对话主题
建筑机器人墙面质量检测系统 - 项目启动与数据准备

## 关键工作

### 1. 项目需求确认
- **应用场景**: 喷涂机器人、石膏抹灰机器人、腻子抹刮机器人的墙面质量检测
- **核心功能**:
  - 墙面平整度检测
  - 墙面缺陷检测（裂缝、空鼓、污渍等）
  - 多设备视频流接入
  - 灵活模型切换架构
  - 设备状态统计（施工时间、休息时间、移动时间）

### 2. 技术约束（重要）
- **视频读取**: 必须使用 OpenCV，FFmpeg 不能长时间运行（已验证）
- **内存管理**: 需要缓存释放机制，支持长时间运行
- **报告需求**: 统计设备一天状态，生成日报

### 3. 数据集构建完成
- **视频来源**: 24 个施工视频（用户提供的 JHMH 系列）
- **帧提取**: 96 帧标准图像（1280x720，OpenCV 提取）
- **划分**: 76 帧训练集 + 20 帧验证集
- **位置**: `dataset/wall_inspection/`

### 4. 半自动标注系统
- **传统 CV 检测器**:
  - 裂缝检测（黑帽变换 + 几何特征）
  - 污渍检测（颜色异常检测）
  - 墙面状态分类（纹理分析）
  - 施工阶段识别（边缘密度分析）
- **标注结果**: 96 帧初步标注，保存在 `semi_auto_labels/semi_auto_labels.json`
- **可视化**: 生成带标注框的图像，方便人工审核

### 5. 检测结果分析
- **污渍检测**: 准确率 ~60%
- **裂缝检测**: 准确率 ~40%，存在结构误识（将设备边缘误判为裂缝）
- **墙面状态**: 准确率 ~50%，网格布检测较准确
- **施工阶段**: 准确率 ~30%，需要更多上下文

### 6. 项目架构设计
```
stream_manager_v2/detectors/
├── wall_defect_detector.py       # 裂缝、污渍、空鼓检测
├── flatness_detector.py          # 平整度检测
├── spray_quality_detector.py     # 喷涂质量检测
└── mesh_detector.py              # 网格布检测
```

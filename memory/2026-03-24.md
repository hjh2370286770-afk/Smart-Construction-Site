### 项目概述

这是一个 **工地安全监控系统**，基于 Python + YOLOv8 实现实时视频流处理和 PPE（个人防护装备）检测。

### 核心功能

1. **多路视频流管理** (`stream_manager.py`)
   - 基于 asyncio 的高并发 RTMP/RTSP 拉流
   - 自动重连机制
   - 帧队列管理 + 跳帧控制
   - 实时状态监控

2. **场景路由引擎** (`scene_router.py`)
   - 支持多种检测场景：安全帽检测、人员计数、危险区域、车辆检测等
   - 动态模型切换
   - 预定义场景配置

3. **PPE 检测器** (`detectors/ppe_detector.py`)
   - 检测类别：安全帽、反光衣、口罩
   - 人员跟踪（ID 分配）
   - 违规检测逻辑
   - 实时可视化（带统计面板）

4. **关键帧提取** (`keyframe_extractor.py`)
   - 根据检测结果智能提取关键帧
   - 可配置触发条件

5. **云端上传** (`cloud_uploader.py`)
   - 支持 HTTP/WebSocket 上传
   - 异步队列管理

### 技术栈

- Python 3.8+
- OpenCV (视频处理)
- YOLOv8 / Ultralytics (目标检测)
- asyncio (异步并发)
- PyTorch (深度学习框架)

## 1. 项目概述

本系统是一套基于计算机视觉和深度学习的**车辆清洗智能识别与管理系统**，专为建筑工地、矿区、港口等场景的出入口车辆清洗监管设计。系统通过实时视频流分析，自动完成车辆检测、车牌识别、进出场管理、清洗判定等全流程业务，实现无人化、智能化的车辆清洗监管。

### 1.1 核心功能模块

| 模块        | 功能描述           | 技术实现                            |
| --------- | -------------- | ------------------------------- |
| **车辆检测**  | 多类型车辆实时检测      | YOLOv8n (COCO预训练)               |
| **车牌识别**  | 车牌定位+号码识别+颜色识别 | YOLOv8s + plate\_rec\_color.pth |
| **车辆跟踪**  | 跨帧车辆ID关联       | IOU贪心匹配算法                       |
| **进出场管理** | 自动判定车辆进场/出场    | 位置趋势分析 + 时间阈值                   |
| **清洗判定**  | 判定车辆是否完成清洗     | 车轮整洁度检测                         |
| **数据管理**  | 记录存储、查询、统计、导出  | SQLite + REST API               |
| **实时推送**  | 事件实时通知前端       | WebSocket                       |

## 3. 核心算法技术优势

### 3.1 系统算法架构

```
┌─────────────────────────────────────────────────────────────┐
│                    车辆清洗识别算法流水线                      │
├─────────────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────────────┤
│  检测层: YOLOv8n 车辆检测 (1280×720降分辨率)                  │
│          └── 输出: 车辆边界框 [x1, y1, x2, y2] + 类别 + 置信度 │
├─────────────────────────────────────────────────────────────┤
│  跟踪层: IOU贪心匹配跟踪器                                    │
│          └── 输出: 跟踪ID + 位置历史 + 出场状态               │
├─────────────────────────────────────────────────────────────┤
│  识别层: YOLOv8s 车牌检测 + CRNN 车牌识别                     │
│          └── 输出: 车牌号 + 车牌颜色 + 颜色置信度             │
├─────────────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────────────┤
│  去重层: SpatialPlateDeduplicator (空间聚类+投票确认)         │
│          └── 最小检测数: 10帧 | 一致性阈值: 80%               │
├─────────────────────────────────────────────────────────────┤
│  业务层: EntryExitManager (进出场+清洗判定)                   │
│          └── 清洗停留阈值: 180秒 | 出场确认: 左侧消失60秒     │
├─────────────────────────────────────────────────────────────┤
│  输出层: 车辆记录 + 统计报表 + WebSocket实时事件              │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 关键算法详解

#### 3.2.1 空间聚类车牌去重算法 (SpatialPlateDeduplicator)

**技术原理**：

- 利用车辆空间位置稳定性，将同一物理车辆的多次检测聚类
- 对聚类内的候选车牌进行投票，只有一致性≥80%的车牌才被确认
- 支持编辑距离≤1的相似车牌合并

**算法优势**：

| 特性    | 说明                  |
| ----- | ------------------- |
| 抗抖动能力 | 单帧误识别不影响最终结果        |
| 自适应阈值 | 空间阈值80像素 + 时间窗口12秒  |
| 格式优先  | 优先选择7位/8位标准长度车牌     |
| 增量确认  | 已确认车辆保留在跟踪池中，避免重复确认 |

**关键代码逻辑**：

```python
# 空间匹配: 计算欧氏距离
distance = sqrt((cx1 - cx2)^2 + (cy1 - cy2)^2)
if distance > spatial_threshold(80px):  # 不是同一辆车
    continue

# 车牌一致性检查
best_plate_votes / total_detections >= min_plate_agreement(0.80)
```

#### 3.2.2 强车牌合并机制 (EntryExitManager)

**技术原理**：

- 基于编辑距离计算车牌相似度
- 相似度>0.60的车牌视为同一车辆的识别变体
- 自动迁移记录到更"标准"的车牌键

**算法优势**：

| 场景    | 处理效果                    |
| ----- | ----------------------- |
| 字符误识别 | "京A12345"和"京A12346"自动合并 |
| 长度不一致 | "京A1234"和"京A12345"择优保留  |
| 二次进场  | 已出场车辆再次识别，标记为reentry    |

#### 3.2.3 静止检测与清洗判定算法

**技术原理**：

- 记录车辆最近10帧的中心位置历史
- 计算X/Y方向的移动范围
- 移动范围<30像素判定为静止
- 静止累计≥180秒且位于清洗区域内 → 判定为已清洗

**算法优势**：

| 特性    | 说明                    |
| ----- | --------------------- |
| 抗微小抖动 | 30像素阈值过滤摄像头轻微晃动       |
| 移动重置  | 大幅移动(>50像素)才重置计时，避免误判 |
| 区域绑定  | 离开清洗区域立即重置，逻辑严谨       |

### 5.2 YOLOv8 核心技术创新

#### 5.2.1 解耦检测头 (Decoupled Head)

| 特性    | YOLOv5 (耦合头) | YOLOv8 (解耦头) | 优势         |
| ----- | ------------ | ------------ | ---------- |
| 结构    | 分类+回归共享卷积    | 分类和回归分支分离    | 任务特异性优化    |
| 收敛速度  | 较慢           | **快30%**     | 损失函数独立优化   |
| 小目标检测 | 一般           | **提升明显**     | 分类分支专注语义特征 |
| 定位精度  | 良好           | **更优**       | 回归分支专注位置特征 |

**原理说明**：

- 耦合头：分类和边界框回归使用同一组特征图，存在任务冲突
- 解耦头：分离为两个独立分支，各自优化，互不干扰

#### 5.2.2 无锚框检测 (Anchor-Free)

| 特性     | YOLOv5 (基于锚框) | YOLOv8 (无锚框) | 优势       |
| ------ | ------------- | ------------ | -------- |
| 预设锚框   | 需K-Means聚类    | **无需预设**     | 简化训练流程   |
| 多尺度适配  | 需多组锚框         | **直接预测**     | 自适应不同尺寸  |
| 训练稳定性  | 依赖锚框质量        | **更稳定**      | 减少超参调优   |
| 特殊形状目标 | 可能匹配不佳        | **直接回归**     | 异形目标检测更准 |

**原理说明**：

- 直接预测边界框中心点到四边的距离，而非基于锚框的偏移量
- 消除锚框与真实框匹配过程中的信息损失

#### 5.2.3 C2f模块 (CSPLayer with 2 Convolutions Fast)

| 特性   | YOLOv5 (C3模块) | YOLOv8 (C2f模块) | 优势          |
| ---- | ------------- | -------------- | ----------- |
| 梯度流  | 单向            | **更丰富**        | 更多跳连，缓解梯度消失 |
| 参数量  | 较多            | **减少约15%**     | 轻量化设计       |
| 特征融合 | 标准            | **更充分**        | 多分支特征拼接     |
| 推理速度 | 快             | **更快**         | 计算效率优化      |
